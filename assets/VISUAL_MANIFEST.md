# Vizuální reference ZZ-01

Všechny soubory v této složce jsou referenční návrhy. Finální UI se má držet jejich společného vizuálního jazyka, nikoli slepě kopírovat jednu náhodnou variantu.

## Závazné principy
- retro arkáda / 8–16bit / CRT ovládací panel
- tmavé námořnické až téměř černé pozadí
- cyan/turkysové pixelové rámečky
- oranžová pro hlavní akce a potvrzení
- světlý text, čitelnost před efektem
- hranaté ovladače, jemné scanlines
- hravé, ale ne dětské
- na mobilu zachovat čitelnost a velké ovládací plochy


## Primární schválená reference
- `references/Výběr tématu a Kolo štěstí.png` — schválená reference pro výběr tématu a Kolo štěstí.
- `icons/Zkouskomat_APP_ICON_MASTER_1024.png` — oficiální master ikona aplikace; nepředělávat bez výslovného zadání.

> Přesný význam jednotlivých schválených obrazovek, včetně průběhu zkoušení, známkování a potvrzení výsledku, určuje `../docs/visual_reference.txt`.
