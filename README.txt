ZZ-01 – oprava návratu z testovacích rolí na administrátora

1. Přepiš v repozitáři stávající index.html tímto souborem.
2. Commit: Oprava přepínání testovacích rolí na skutečného administrátora
3. Push origin.
4. Po nasazení dej na GitHub Pages Ctrl+F5.
5. Otestuj: Administrátor → Testovací učitel → Testovací Šéfová → Administrátor.
6. Potom otevři Administrace školy → Profil školy a ověř kód školy pro žáky.

Součástí této verze zůstává i předchozí studentské přihlášení bez e-mailu.
