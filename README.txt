ZZ-01 – žákovské výzvy + ABCD testy

Nově:
- učitel může při tvorbě výzvy zvolit Test ABCD nebo Krátkou odpověď
- ABCD test má čtyři možnosti A, B, C, D a jednu správnou volbu
- žák vybírá odpověď pomocí čtyř přehledných voleb
- na test je jeden pokus
- za správnou odpověď získá nastavené kladné body
- po odevzdání se zobrazí správná možnost
- původní textové výzvy zůstávají funkční

Backendová migrace 010 už byla aplikována do produkčního Supabase projektu.


Doplnění – testy a hádanky v profilu učitele:
- každý schválený učitel má v Nastavení → Můj profil tlačítko „Vytvořit test / hádanku“
- nové ABCD testy a hádanky se publikují všem žákům školy
- všichni žáci školy je vidí jako dobrovolné výzvy
- každý učitel spravuje své výzvy, administrátor může vidět/spravovat školní obsah podle backendu
- body za správné odpovědi se připisují do herní peněženky žáka
