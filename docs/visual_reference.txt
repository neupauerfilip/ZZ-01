ZKOUŠKOMAT ZZ-01
VIZUÁLNÍ REFERENCE PRO WORK
Průběžně aktualizovaný společný soubor

ÚČEL SOUBORU
Tento soubor je jediný společný přehled schválených vizuálních referencí aplikace Zkouškomat ZZ-01.
Work má při další práci používat zde uvedené obrázky jako závazné vizuální reference a nemá vytvářet nový výtvarný styl.

PRAVIDLO PRO DALŠÍ PRÁCI
Při každém novém schváleném obrázku:
1. obrázek dostane jednoznačný a popisný název,
2. uloží se mezi podklady projektu Zkouškomat ZZ-01,
3. do tohoto jediného souboru se doplní nový záznam,
4. nevytváří se nový doprovodný textový soubor pro každý obrázek,
5. starší záznam se upraví pouze tehdy, když nový obrázek nahrazuje starší verzi.

--------------------------------------------------
ZÁVAZNÝ VIZUÁLNÍ STYL – „ZKOUŠKOMAT VIZUÁL“
--------------------------------------------------

- retro arkádový / pixel-art styl
- tmavě modré až téměř černé pozadí
- tyrkysové / cyan rámečky, linky a sekundární prvky
- oranžová jako výrazná akcentní barva
- světlý krémový / bílý text
- pixelová typografie
- jednoduché, dobře čitelné 8bit/16bit ilustrace
- lehký CRT / scanline dojem
- hranaté pixelové rámečky
- vysoký kontrast
- čitelnost a praktičnost mají přednost před dekorací
- nepoužívat moderní flat/cartoon styl
- nepoužívat generický neonový vzhled, který se odchyluje od stávajících obrazovek
- horní část aplikace má používat pouze název „ZKOUŠKOMAT“
- nepoužívat slogan „Učení má větší smysl“ v hlavičce obrazovek

--------------------------------------------------
INSTRUKCE PRO WORK
--------------------------------------------------

Při převodu těchto referencí do skutečné aplikace:

- NEVKLÁDAT celé screenshoty jako pozadí aplikace.
- Obrazovky vytvořit jako skutečné interaktivní HTML/CSS/JS rozhraní.
- Obrázky používat jako vizuální předlohu.
- Samostatné ilustrace, ikony, avatary, trofeje a další grafické assety lze používat jako obrazové soubory.
- Zachovat funkční logiku aplikace.
- Nevymýšlet nové prvky, které nejsou v zadání nebo schválených funkcích.
- Pokud je nový návrh v rozporu se starším obrázkem, platí nejnovější schválená reference a tento textový soubor.
- Při pochybnosti dát přednost jednoduchosti, čitelnosti a již schválenému stylu.
