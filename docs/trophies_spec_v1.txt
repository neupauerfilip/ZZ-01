======================================================================
NOVÝ SYSTÉM TROFEJÍ – 20 ZÁKLADNÍCH TROFEJÍ × 4 STUPNĚ
======================================================================

CÍL:
Rozšířit současný systém achievementů/trofejí bez zbytečného přidávání
dalších a dalších samostatných odměn.

Uživatelsky používat především pojem:
TROFEJ

Pojem „achievement“ může zůstat pouze interně v kódu, pokud je potřeba
kvůli zpětné kompatibilitě.

Každá veřejná trofej má 4 postupové stupně:

1. BRONZ
2. STŘÍBRO
3. ZLATO
4. DIAMANT

DŮLEŽITÉ:
- STUPEŇ trofeje a VZÁCNOST trofeje jsou dvě různé věci.
- Stupeň říká, jak daleko učitel v konkrétní trofeji postoupil.
- Vzácnost říká, jak neobvyklá / náročná je samotná trofejní řada.

Vzácnosti zůstávají:
- BĚŽNÁ
- NEOBVYKLÁ
- VZÁCNÁ
- EPICKÁ
- LEGENDÁRNÍ

Příklad:
„Kolo osudu“ může být VZÁCNÁ trofej a zároveň ji učitel může mít
na stupni BRONZ / STŘÍBRO / ZLATO / DIAMANT.

======================================================================
CHOVÁNÍ SYSTÉMU
======================================================================

- Učitel získává vždy nejvyšší dosažený stupeň trofeje.
- Nižší stupně zůstávají v historii jako dříve dosažené.
- Při dosažení dalšího stupně se stejná trofej v Kabinetu nevytvoří podruhé.
  Pouze se její vzhled a označení povýší.
- Datum získání každého stupně se uloží samostatně.
- Trofej se po získání nesmí zpětně ztratit, ani pokud se později změní
  aktuální hodnota některého ukazatele.
- Každý nový stupeň může vyvolat obrazovku:
  „NOVÁ TROFEJ!“
  + název
  + nový stupeň
  + vzácnost
  + krátký popis
  + „ULOŽENO DO KABINETU“

======================================================================
TAJNÉ TROFEJE
======================================================================

Tajné trofeje nejsou součástí výše uvedených 20 veřejných řad.

Pravidla:
- tajná trofej se nezobrazuje ve „Vše co mohu získat“,
- nezobrazuje se ani jako „???“,
- před získáním pro ni není v Kabinetu prázdné místo,
- po získání se objeví jako normální objevená trofej,
- tajná trofej může mít také více stupňů, ale není to povinné,
- současný „Tajný pohár“ lze zachovat jako první tajnou trofej.

======================================================================
KABINET TROFEJÍ
======================================================================

Kabinet trofejí má působit jako skutečná pixelová vitrína / police.

Každá veřejná trofej má jednu pozici.

Na kartě / polici zobrazit:
- pixelový obrázek trofeje,
- název,
- vzácnost,
- aktuální dosažený stupeň,
- progres k dalšímu stupni.

Příklad:
KOLO OSUDU
STŘÍBRO
15 / 40 k dalšímu stupni
Vzácnost: VZÁCNÁ

Pokud ještě není získán ani Bronz:
- zobrazit tmavou siluetu veřejné trofeje,
- zobrazit název,
- zobrazit podmínku pro Bronz.

Pokud je dosažen Diamant:
- zobrazit „MAX“ nebo „DIAMANT DOKONČEN“,
- další progress bar už nezobrazovat.

VZHLED STUPŇŮ:
- stejné základní pixelové vyobrazení trofeje,
- Bronz / Stříbro / Zlato / Diamant mění materiál, rámeček a drobný efekt,
- nevytvářet čtyři různé obsahové trofeje,
- učitel má stále jeden předmět, který se vizuálně povyšuje.

======================================================================
„VŠE CO MOHU ZÍSKAT“
======================================================================

Současné tlačítko:
„Vše co mohu získat“

zobrazí 20 veřejných trofejních řad.

Řazení:
1. podle vzácnosti
2. uvnitř vzácnosti podle názvu nebo pevného pořadí

U každé řady:
- název,
- ikona / pixelový obrázek,
- vzácnost,
- aktuální stupeň,
- čtyři milníky,
- aktuální progres,
- získané stupně označit,
- další stupeň zvýraznit.

Tajné trofeje se zde nikdy neukazují před získáním.

======================================================================
DATOVÝ MODEL PRO IMPLEMENTACI
======================================================================

Doporučený nový katalog:

trophyDefs = [
  {
    id,
    name,
    rarity,
    hidden,
    visualId,
    metric,
    tiers: [
      { id:'bronze', label:'Bronz', target:... },
      { id:'silver', label:'Stříbro', target:... },
      { id:'gold', label:'Zlato', target:... },
      { id:'diamond', label:'Diamant', target:... }
    ]
  }
]

Pro kombinované trofeje může tier místo jednoho target obsahovat:
requirements:{...}

Stav konkrétního učitele:

teacherTrophies[teacherId][trophyId] = {
  highestTier: 0 | 1 | 2 | 3 | 4,
  unlockedAt: {
    bronze: timestamp | null,
    silver: timestamp | null,
    gold: timestamp | null,
    diamond: timestamp | null
  }
}

0 = nezískána
1 = Bronz
2 = Stříbro
3 = Zlato
4 = Diamant

DŮLEŽITÉ:
- neukládat pouze „aktuálně splněno“,
- ukládat datum skutečného odemčení každého stupně,
- tím se zabrání ztrátě historicky získané trofeje.

======================================================================
MIGRACE ZE SOUČASNÝCH ACHIEVEMENTŮ
======================================================================

Při přechodu nesmí učitel přijít o již získané odměny.

Doporučené mapování:

first_exam / První zkoušení
→ KUS KŘÍDY – minimálně Bronz

three_classes / Třídní turista
→ TŘÍDNÍ TURISTA – odpovídající stupeň podle aktuální hodnoty

eight_topics / Pestrý repertoár
→ PESTRÝ REPERTOÁR – odpovídající stupeň

five_wheels / Kolo rozhodlo
→ KOLO OSUDU – odpovídající stupeň

locker_luck / Šatnář štěstěny
→ ŠKOLNÍ SKŘÍŇKA – odpovídající stupeň

veteran / Veterán ZZ-01
→ VETERÁN ZZ-01 – minimálně Bronz

ten_exams / Desítka
→ podle aktuálního počtu dokončených zkoušení přepočítat KUS KŘÍDY
  a zachovat historickou odměnu v migračním záznamu, pokud je potřeba.

secret_clean / Tajný pohár
→ zachovat jako tajnou trofej mimo veřejných 20.

Migrace musí být jednorázová a idempotentní:
- opakované načtení aplikace nesmí trofeje znovu duplikovat,
- přidat version flag pro trophy schema.

======================================================================
VYHODNOCOVÁNÍ A ODEMKNUTÍ
======================================================================

Vyhodnocení veřejných trofejí spustit po událostech, které mohou změnit progres:
- dokončení zkoušení,
- uložení známky,
- použití tématu,
- roztočení kola,
- výskyt / použití skříňky,
- použití propustky,
- dokončení školní výzvy,
- uzavření sezóny.

Po každém vyhodnocení:
1. zjistit aktuální hodnotu metriky,
2. porovnat s jednotlivými stupni,
3. zjistit nejvyšší nově dosažený stupeň,
4. uložit datum odemčení,
5. vytvořit herní událost,
6. zobrazit „NOVÁ TROFEJ!“ pouze při skutečně novém stupni.

Nesmí docházet k:
- opakovanému udělení stejného stupně,
- dvojímu zápisu po dvojkliku,
- ztrátě získaného stupně při pozdějším poklesu aktuálního ukazatele.
